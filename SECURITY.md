# Security policy

## Reporting a vulnerability

Please report security vulnerabilities in this plugin privately through GitHub's private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability**, or open https://github.com/irashack/jellyfin-plugin-sso/security/advisories/new directly. Do not open a public issue, pull request or discussion for a vulnerability.

Please include the plugin version (shown on Jellyfin's plugin page), the Jellyfin version, the provider type (OpenID Connect or SAML, and which identity provider) and the steps that show the problem. If you used an LLM or other automated tool to find the issue, confirm it by hand first.

We will acknowledge the report in the advisory, keep you informed there and credit you in the advisory unless you prefer not to be. Please don't disclose the vulnerability publicly until a release with the fix has been out for 30 days.

This fork shares most of its code with [K0lin/jellyfin-plugin-sso](https://github.com/K0lin/jellyfin-plugin-sso). Report to us either way; if the problem is in code both forks share, we will tell K0lin's maintainers through their own security contact.

## Supported versions

Only the latest release receives security fixes.
